# Turkish reading dictionaries

Turkish-to-Turkish, Turkish-to-English, and English-to-Turkish dictionaries for KOReader and Yomitan. Turkish lookup includes inflections and frequency ranks.

Download from the [latest release](https://github.com/namidanokisetsu/turkdict/releases/latest):

| App | Download | Installed size |
| --- | --- | --- |
| KOReader | `turkdict-koreader.zip` (261 MiB) | 885 MiB with all optional dictionaries, before caches |
| Yomitan | `turkdict-yomitan.zip` (111 MiB) | Depends on imported dictionaries |

Includes TDK, KeNet, Wiktionary, and Tureng. Install only the dictionaries you want.

## KOReader

Extract the bundle, replace the old dictionary folders in `data/dict/`, and restart KOReader. Enable your dictionaries in **Dictionary settings**.

Turkish inflected-word lookup is included. For English inflections, enable **fuzzy search**. Etymology and morphology are optional.

## Yomitan

Extract the bundle and replace older imports. For Turkish lookup, import **Turkish Forms** and your chosen dictionaries. Frequency and etymology are optional.

Select **Turkish**, enable **Use deinflections** for **Turkish Forms**, and set search resolution to **Word**.

For English lookup, use an English profile with **EN-TR Tureng** only. In that dictionary's settings, turn off **Part of speech filtering** so inflected words can match their base forms.
